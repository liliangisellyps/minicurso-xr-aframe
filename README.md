# Minicurso: Realidade Estendida com A-Frame

Material do minicurso de Realidade Estendida (XR) com A-Frame, do estágio docência em
Computação Gráfica (UFAL, Instituto de Computação).

O minicurso tem 2 aulas de 2 horas:

- **Aula 1:** fundamentos de XR e a primeira cena no navegador
- **Aula 2:** componentes próprios e interação
